# Adereso brand tokens (for video)

Sampled from adereso.ai (2026-09-30) and the assets the user supplied.

## Colour

| Token | Value | Use |
|---|---|---|
| `--bg` | `#0C0C0D` | Stage / cutaway background (the site is dark) |
| `--surface` | `#141414` | Cards, secondary buttons |
| `--surface-grad` | `linear-gradient(#232427, #161719)` | Raised cards, product UI panels |
| `--line` | `rgba(255,255,255,.08)` | Card borders, dividers |
| `--text` | `#FFFFFF` | Headlines, captions |
| `--muted` | `rgba(255,255,255,.55)` | Secondary text |
| `--accent` | `#FFD540` | Brand yellow: CTA pills, keyword highlight. Text on it is `#0C0C0D` |
| `--success` | `#52CE5E` | Positive states, checks |
| `--whatsapp` | `#25D366` | WhatsApp-specific UI only |
| `--blue` | `#5B9BFF` | Secondary data accent, sparingly |

## Type

- **Outfit** (variable 300–700): `brand/fonts/Outfit-Variable-latin.woff2`. The latin subset covers Spanish (á é í ó ú ñ ¿ ¡).
- Headlines: weight 500, letter-spacing −0.04em, line-height ~1.04 (the site's h1 is 61px/64px, −2.46px).
- UI labels and buttons: weight 500, sentence case.
- Pills are fully rounded; product UI cards use ~12–20 px radii with a 1 px `--line` border.

## Logo

`brand/logo.png`: white wordmark with icon on transparent, 566×113. Use it at ≤ 420 px wide in 1080-wide video; for anything larger ask for a vector file.

## Voice

Spanish (LatAm). Sells AI agents for sales and support on WhatsApp and other channels for e-commerce ("Convierte conversaciones en ventas con IA"). Meta Business Partner, Shopify partner.

## Transcription glossary

Whisper mishears brand terms. Fix these before captions: "Ereso" / "a Ereso" → "Adereso"; "IA" stays "IA"; "e-commerce" stays lowercase.
